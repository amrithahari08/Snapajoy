# Snapajoy Homepage Redesign Notes

## Audience Priority

- Primary audience: memory keepers, about 60 percent.
- Secondary audience: urban gift buyers, about 40 percent.
- Memory keepers matter most because they are more likely to return for future books.
- The homepage should still feel WhatsApp-native, emotionally safe, and easy to start.

## Design Implication

The redesign should lean toward a refined, lasting keepsake experience rather than a gift-only landing page. It should keep the low-friction WhatsApp flow visible, but the emotional center should be preservation, repeat creation, and family memory continuity.

## Trust Positioning

- The homepage must build brand trust, not only explain WhatsApp convenience.
- The main promise should combine high-quality photo books, on-time delivery, and easy creation through WhatsApp.
- "First design in less than 10 minutes" can become a strong proof point if Snapajoy can consistently deliver it.
- Trust should feel practical: clear quality cues, delivery confidence, preview before print, and a human-guided process.

## Proof Assets

- Use real printed books with open spreads as the main product proof.
- The user will replace placeholder images later.
- The website should label where each real image belongs:
  - Hero: best open photo book spread, warm and premium, with hands or table context if available.
  - Quality section: close-up of paper, cover, binding, print texture, or packaging.
  - Process section: phone/WhatsApp next to printed book or draft preview.
  - Examples section: open books grouped by use case, such as family yearbook, wedding, baby, travel, and festival.
- Process proof can include preview before print, edit requests, approval before payment or print, and human support.

## Brand Feel

- Target feel: accessible premium.
- Snapajoy should feel polished, trustworthy, warm, and priced for Indian families.
- Avoid a distant luxury tone. Keep the service human and easy to start.
- The visual direction can borrow restraint from MILK Books, but the result should feel friendlier and more familiar for an Indian audience.

## Selected Homepage Approach

- Direction: Keepsake Trust Homepage.
- Lead with memory preservation and brand trust.
- Keep WhatsApp speed visible in the hero, but do not make speed the whole identity.
- Use product quality, preview-before-print, edit requests, and approval before print as the main trust sequence.
